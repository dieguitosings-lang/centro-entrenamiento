# Centro de Entrenamiento

Página de estudio para 4° de básica, pensada para niños con TDAH: misiones cortas de 10 minutos los fines de semana, pausas activas, temas por materia con preguntas y audio, práctica de tablas de multiplicar y un sistema de niveles y canastas para motivar.

- Materias: Matemática, Language Arts, Natural Science, Lengua y Literatura, Estudios Sociales, Environmental Science.
- Un solo archivo (`index.html`), sin servidor. El progreso se guarda en el navegador de cada dispositivo; se puede pasar a otro con el respaldo del panel de papás.
